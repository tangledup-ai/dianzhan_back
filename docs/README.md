# docs — 修改与修复记录

本目录存放每次批量修改/修复的详细记录：**解决了什么问题、为什么、怎么改的、达到什么效果、涉及哪些文件**。

## 维护约定

1. 每完成一批修改，新建一篇 `YYYY-MM_主题.md`（如 `2026-09_审批流安全加固.md`），不要多批混在一篇里。
2. 每条记录按固定结构写：**问题现象 → 原因 → 修复 → 效果/验证 → 涉及文件 → 提交号**。
3. 涉及业务口径的决策（如"主体以电表为准"、"尾期金额留空"），必须写进文档，避免后人不知道口径而重复修改或改回去。
4. 全量体检类报告（问题清单）以 `复检报告_YYYYMMDD.md` 命名，修复后在其条目上标注状态。
